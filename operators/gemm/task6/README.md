# TASK6：HGEMM 深度优化

## 实验环境

- GPU：NVIDIA RTX 5070 Ti
- CUDA：13.0
- Architecture：sm_120
- 输入精度：FP16
- 累加与输出精度：FP32

## V1：TMA 与多 Warp 分块

### 优化方法

- Block Tile 扩展至 128 × 128 × 32，提高数据复用率。
- 每个 Block 包含 8 个 Warp，划分为 4 个计算组。
- 每个 Warp 负责 32 × 64 的输出区域，维护 8 个累加片段。
- 使用 TMA 完成全局内存到共享内存的数据搬运。
- 采用 4 × 2 Block Swizzle，改善 L2 Cache 数据复用。
- 使用单缓冲结构，通过 Barrier 保证搬运与计算的正确性。

### 性能结果

测试规模：M = N = K = 4096，预热 10 次，计时 20 次。

| 版本 | 执行时间 (ms) | TFLOPS | 正确性 |
|---|---:|---:|---|
| V1 | 2.031906 | 67.640424 | PASS |

cuBLAS 最大绝对误差：0。

### 后续优化方向

当前采用单缓冲结构，TMA 搬运与 Tensor Core 计算未实现重叠。后续通过多级缓冲及流水线调度进一步提高计算效率。

## V2：双缓冲流水线

### 优化方法

在 V1 的基础上引入 Double Buffering（双缓冲）：

- 分配两套 A、B 共享内存缓冲区及独立的 Barrier。
- 在主循环前预取第一个 K 分块。
- 通过 `phase` 控制两个缓冲区交替读写。
- 将下一阶段的 TMA 搬运与当前阶段的 WMMA 计算重叠。

保持矩阵分块参数、Warp 映射及计算逻辑不变。

### 实验结果

| 版本 | 执行时间 (ms) | 性能 (TFLOPS) |
|---|---:|---:|
| V1 | 2.031906 | 67.640424 |
| V2 | 1.942786 | 70.743241 |
| cuBLAS | 1.418915 | 96.861994 |

- 正确性验证：PASS
- 最大绝对误差：0
- 共享内存数据区：32 KiB
- 相比 V1 性能提升：4.59%
- cuBLAS 相对性能：73.04%

### 实验结论

双缓冲通过异步搬运与计算重叠，提高了 GEMM 吞吐量，但同时增加了共享内存占用。
